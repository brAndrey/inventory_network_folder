# inventory_network_folder

Скрипт инвентаризации структуры сетевых папок. Рекурсивно обходит заданные каталоги и выгружает иерархию папок в CSV-отчёт.

Только стандартная библиотека Python 3, без внешних зависимостей.

## Возможности

- Обход нескольких корневых папок из конфигурационного INI-файла.
- Ограничение глубины сканирования (`max_depth`).
- Настраиваемые кодировка и разделитель CSV.
- Логирование в консоль и файл `Log/logs.log` с ротацией.
- Запуск через `.bat` (вручную или в Планировщике задач Windows).

## Файлы

| Файл | Назначение |
|------|-----------|
| `main.py` | Точка входа, связывает конфиг, логгер, сканер и запись CSV. |
| `scanner.py` | Обход папок (`os.walk`) и формирование строк CSV. |
| `config_loader.py` | Поиск и чтение INI-файла, разбор корней и опций. |
| `logger_setup.py` | Создание логгера с ротацией файлов. |
| `folders.ini` | Настройки: опции и список корневых папок. |
| `run_inventory.bat` | Запуск скрипта в Windows. |

## Настройка

Корневые папки и опции задаются в `folders.ini`:

```ini
[OPTIONS]
sort_dirs = false
max_depth = 5
encoding = utf-8-sig
delimiter = semicolon
root_label = name

[ROOTS]
root1 = \\server\share1
root2 = \\server\share2
```

## Запуск

```bat
run_inventory.bat
```

Либо напрямую:

```bat
python main.py
```

Можно указать свой INI-файл первым аргументом:

```bat
python main.py my_config.ini
```

## Результат

В папке `Report/` создаётся CSV-файл вида `folders_chain_<дата_время>.csv`, где каждая строка — цепочка папок:

```
корень;родительская_папка;текущая_папка
```
