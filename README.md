# folder_monitor

Система мониторинга структуры сетевых/локальных папок организации. Каждый час
сканирует заданные корневые папки, сохраняет структуру и количество файлов в
SQLite, сравнивает с предыдущим сканом и формирует отчёты об изменениях:
новые, удалённые, перемещённые папки и папки с аномальным уменьшением
количества файлов.

Только стандартная библиотека Python 3.8+, без внешних зависимостей.

## Ключевая особенность производительности

В папках очень много файлов, поэтому система **не измеряет размеры файлов** и
**не вызывает `stat()`** для файлов. Единственная метрика содержимого папки —
количество файлов непосредственно в ней (без вложенных папок). Для подсчёта
используется только `os.scandir()` и `entry.is_file(follow_symlinks=False)`,
что работает на кэшированных метаданных системного листинга каталога.

## Конфигурация (`config.ini`)

### Секция `[ROOTS]`

Каждая строка содержит адрес папки и индивидуальную глубину сканирования,
разделённые `;`:

```ini
[ROOTS]
root1 = \\fileserver\documents;3
root2 = \\fileserver\archive;1
root3 = D:\Docs\Проекты;5
root4 = \\fileserver\hr;2
```

Глубина:
- `0` — только сама корневая папка;
- `1` — корень + папки первого уровня;
- `N` — корень + N уровней;
- `-1` — без ограничения;
- если глубина не указана (строка без `;`) — считается `-1`.

### Секция `[OPTIONS]`

| Опция | По умолчанию | Описание |
|-------|-------------|----------|
| `db_path` | `folder_monitor.db` | Файл SQLite (относительно папки скрипта). |
| `log_dir` | `Log` | Папка логов. |
| `report_dir` | `Reports` | Папка отчётов. |
| `retention_days` | `7` | Хранение сканов (дни). |
| `file_count_decrease_percent` | `20` | Порог уменьшения файлов, %. |
| `file_count_decrease_min` | `10` | Порог уменьшения файлов, абсолют. |
| `scan_timeout_minutes` | `55` | Максимальное время сканирования. |
| `count_hidden_files` | `true` | Считать ли скрытые/служебные файлы. |

Аномалия уменьшения файлов срабатывает только при одновременном выполнении
обоих порогов (процент И абсолют).

### Секция `[ALERTS]` (опционально)

```ini
[ALERTS]
enabled = false
email_to = admin@example.com
smtp_server = smtp.example.com
smtp_port = 587
```

## Схема базы данных

Основные таблицы: `scans` (запуски), `folders` (структура папок скана),
`events` (значимые события), `scan_errors` (ошибки), `moves` (перемещения).

- Соединение открывается один раз на всё время работы, режим WAL.
- `PRAGMA foreign_keys=ON` обеспечивает каскадное удаление связанных записей
  при очистке старых сканов.

## Детекция перемещений

Папка считается перемещённой при сопоставлении «исчезнувших» и «появившихся»
папок внутри одного корня. Уровни уверенности:

- **high** — совпадают имя, `content_hash` и `file_count`;
- **medium** — совпадают имя и `content_hash` (число файлов изменилось);
- **low** — совпадает только имя, число файлов отличается не более чем на 10%,
  и такого имени нет среди неизменённых папок корня.

`content_hash` — SHA-256 от сортированного списка **имён** файлов (без размеров),
поэтому перемещение детектируется быстро даже при большом количестве файлов.

## Запуск

Вручную или через Планировщик задач Windows:

```bat
run_monitor.bat
```

Либо напрямую:

```bat
python main.py
```

Можно указать другой INI первым аргументом:

```bat
python main.py my_config.ini
```

## Отчёты

После каждого сканирования в папке `Reports/` создаются:

- `report_YYYYMMDD_HHMMSS.csv` — полный отчёт об изменениях;
- `report_YYYYMMDD_HHMMSS.html` — человекочитаемый отчёт (перемещения с цветовой
  кодировкой: high — зелёный, medium — жёлтый, low — красный);
- `moves_YYYYMMDD_HHMMSS.csv` — только перемещения папок.

Формат CSV перемещений:

```
detected_at;root;old_path;new_path;folder_name;confidence;file_count
```

## Логирование

- Файл: `Log/monitor.log`, ротация 5 файлов по 5 МБ.
- Формат: `2026-09-09 14:00:01 [INFO] Сообщение`.
- Значимые события дублируются в таблицу `events`.
